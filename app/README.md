# Bản React + Tailwind (đang làm dần)

Làm lại trang chủ bằng React, Tailwind CSS và Vite. Trang cũ trong `prompt2/` vẫn là bản đang chạy thật.

```bash
cd app
nvm use 20
npm install      # chỉ làm lần đầu
npm run dev      # chạy thử trên máy, mở địa chỉ hiện ra (thường là http://localhost:5173)
npm run build    # tạo bản đưa lên mạng trong thư mục dist/
```

Cấu trúc: `src/App.jsx` ghép các mảnh giao diện trong `src/components/`; màu và font nằm trong `src/index.css`.
